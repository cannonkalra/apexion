# Security Policy

## Supported Versions

Apexion is pre-1.0 software under active development. Only the latest release on
the `main` branch (the newest minor version) is supported with security fixes.
Please upgrade to the newest release before reporting a vulnerability.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately. **Do not
open a public GitHub issue for security vulnerabilities.**

To report a vulnerability, either:

- Email **cannonkalra@gmail.com**, or
- Use GitHub's [private security advisories](https://github.com/cannonkalra/apexion/security/advisories/new).

Please include as much of the following as you can:

- Steps to reproduce the issue.
- The impact and potential severity.
- The affected version or commit.

We aim to acknowledge your report within **72 hours** (best effort) and will
work with you on a fix and coordinated disclosure. Thank you for helping keep
Apexion and its users safe.
